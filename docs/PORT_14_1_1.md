# PG3D 14.1.1 native port

This branch targets the supplied ARMv7 IL2CPP build only.

## Analysis inputs

- `libil2cpp.so` SHA-256: `5e4ab38ad6388ab187d0e7441ea6833838414fee5720d9dd483bf1e10eb33219`
- `global-metadata.dat` SHA-256: `3004f5e89c6d3104470252dd036bc38747f7b4b7e97151a233b445e6fe8851f6`
- `dump1411.cs` SHA-256: `484a6041d330b587aaed702232c58423be59d495557ba84fdef64bf6a8ca24d1`

The binary is ELF32 ARM/EABI5 with build ID
`d5544e28598b58b162d964379377716dfc59c931`.

## Ported differences

### APK re-signing

`AppsMenu.<Start>c__Iterator1.MoveNext()` compares the installed certificate
hash with `AppsMenu.intendedSignatureHash`. A mismatch persists a tamper mark
and queues the obfuscated `ClosingScene` path. The port verifies the exact ARM
opcodes around RVA `0xA9A984` before changing only the signature-mismatch
conditional branch to the existing accepted path. Package-name and error/null
checks remain stock. If the expected instructions do not match, the patch
refuses to run.

The inherited managed anti-punishment guards remain enabled as defence in
depth (`Switcher.get_AbuseMethod`, `AdsConfigManager.GetCheatingMethods`, the
delayed scene iterator and `CheatDetectedBanner`).

### Photon squad connection

`GameConnect.ConnectToPhotonSquad()` became
`ConnectToPhotonSquad(bool siegeSquad)`. The 14.1.1 hook preserves that value
and reapplies the same explicit Photon Cloud route before forwarding.

### Lobby catalogue

`LobbyItemsController.AddItemNow(item)` became
`AddItemNow(item, bool autoEquip = true)`. The new module passes
`autoEquip=false` while retaining the stock ownership creation and save path,
so a bulk grant does not continuously replace the selected lobby item.

### Post-match screen

`OnRewardShow` and `OnRewardAnimationEnds` no longer exist. In 14.1.1,
`AnimationEventShowRewardsFinished()` starts `ShowRewardsCoroutine()` via
`OnRewardFirstWindowShow(0)`. The port keeps the panel-opening animation but
suppresses that coroutine, resets `isRewardsShowing`, and resets the stale
`isCancelHideAvardPanel` guard before every OK press. Stock
`HideAvardPanel()` still calls `ShowEndInterface(winner, winnerCommand)` and
opens the standard player/team table.

## Static compatibility result

All 87 managed methods and fields used by the inherited project were checked
against `dump1411.cs`. Eighty-five retained their 13.2.1 signatures; the two
changed targets above have dedicated 14.1.1 replacements. Clan crafting,
free details, retired arsenal, tutorial/time compatibility, Photon diagnostics,
progression, custom-hunger and cheat-banner guards retain matching metadata
signatures.

## Device validation

Use a disposable/test save for the first launch and verify logcat contains:

- `14.1.1: APK re-sign compatibility active`
- `14.1.1: squad Photon cloud-route hook armed`
- `lobby-14.1.1: catalogue grant armed`
- `post-match-14.1.1: armed`
- `init: 14.1.1 port ready`

Then test lobby → armory, squad and normal matchmaking, two consecutive
matches, post-match OK, one clan/detail craft, and an app restart.
